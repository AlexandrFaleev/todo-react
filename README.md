# ToDo List на React.JS
Держите все ваши задачи в одном месте

## Возможности приложения
Данное приложение позволит вам:
- Хранить задачи
- Добавлять новые
- Удалять задачи
- Отмечать задачи как выполненные
- Искать нужную задачу
- Посмотреть первую невыполненную задачу

## Как скачать?
Для установки скопируйте себе данный репозиторий или скачайте его архивом. Откройте терминал по адресу папки и введите последоваельно следующие команды:
```bash
#Установка зависимостей проекта
npm install

#Запуск api и dev-режима проекта
npm run server
```
